# NOVA — сайт сети лаунж-кафе

Демонстрационный сайт NOVA для трёх заведений Минска. Отдельный проект, не связанный с AVE.

## Текущее состояние

- Мобильная и десктопная версия, страницы Зыбицкой, Победителей и Востока.
- На странице отдельного заведения контекст меню и бронирования фиксируется на нём.
- Форма бронирования работает только в демонстрационном режиме: реальные сообщения в Telegram не отправляются.
- Изображения — демонстрационные; реальных ссылок QR-меню пока нет.
- Рабочий адрес демо: https://nova-lounge-demo.blacklivi-olx.workers.dev/

## Разработка и публикация

Статические файлы находятся в `public/`. Конфигурация Cloudflare — `wrangler.jsonc`. Сборка не требуется.

```sh
npm install
npx wrangler deploy
```

Для Cloudflare Workers Builds: репозиторий `blacklivi/nova-lounge-website`, ветка `main`, пустая команда сборки, команда публикации `npx wrangler deploy`.

**Никогда не размещать ключ Telegram-бота в исходном коде или GitHub.** Для будущей серверной интеграции использовать Cloudflare Secrets.
