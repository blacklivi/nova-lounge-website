# Решение о запуске NOVA

**NO-GO для переключения DNS до ручной приёмки.**

Технический блокер Cloudflare закрыт. На отдельном защищённом HTTPS preview подтверждены три сквозные брони, запись в D1, доступ и полномочия сотрудников, история статусов и публикация изображения в отдельную R2. Cloudflare подтвердил, что сборка PR #82 получает 100% production-трафика, а независимый read-only прогон проверил работу публичных форм и отказ защищённых API без сессии. [Доказательства](STAGING-ACCEPTANCE.md)

Осталось два условия:

1. На физическом iPhone открыть формы трёх площадок в Safari и проверить с открытой клавиатурой маску, прокрутку, закрытие и доступность кнопки отправки. Форму при этой проверке можно не отправлять.
2. Сверить часы, телефоны, меню, Instagram и актуальность афиши. На каждой площадке назначить основного и резервного сотрудника и запустить ручную обработку заявок. [Регламент без Telegram](STAFF-RESERVATIONS-SOP.md)

После этих двух подтверждений DNS можно переключать отдельной согласованной операцией. Telegram не обязателен для запуска при действующем ручном процессе.
