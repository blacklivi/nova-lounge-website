## Оставшиеся ограничения

- Полная матрица 11 ширин (320, 360, 375, 390, 430, 768, 1024, 1280, 1440, 1920, 2560) в обеих локализациях ещё не проверена скриншотами. Browser Rendering API ограничивал частоту запросов (429).
- Настоящий Safari на iPhone требует отдельного теста. Touch-устройства используют нативные date/time/select picker; их системные акцентные цвета могут отличаться от NOVA и не полностью контролируются CSS.
- Отдельную сквозную проверку авторизованной админки с сохранением фотографий в production не проводили: недопустимо изменять реальные данные ради теста. В preview записывающие методы изолированы с отдельной БД.
- Не выполнены нагрузочные, Lighthouse и полноценные a11y/keyboard/focus проверки.
- Настоящие фотографии заведений/еды, подтверждённые адреса, часы, соцсети, ссылки трёх QR-меню и Telegram для брони должны предоставляться владельцем. До этого изображения демонстрационные, а заявки реально не отправляются.
