# NOVA — восстановление после лимита Work

Исходник новой версии перенесён из `nova-visual-preview` в отдельную ветку `design-polish-20261023`. Здесь сохранены старые серверные маршруты, D1/R2, админка и Worker конфигурация из `main`.

## Важные условия

- Не подменять основной сайт без проверки `/admin`, `/events`, `/api/content` и формы.
- Не включать реальные Telegram-заявки до подключения проверенного токена и согласованного чата.
- Изображения на страницах остаются демонстрационными до получения реальных фотографий NOVA.
- `main` не изменялся при восстановлении новой версии.
- Шрифты Manrope взяты из ранее опубликованного preview, лицензия OFL сохранена рядом с веб-шрифтами.

## Тесты

Выполнить проверку: 320, 360, 375, 390, 430, 768, 1024, 1280, 1440, 1920, 2560 px; два языка; три заведения; меню; афишу; админку; модальное бронирование и валидацию телефона.
