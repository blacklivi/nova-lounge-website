# NOVA — редактор страниц (2026-11-07)

## Вход
Адрес: `/admin`. Используется существующий пароль редактора и защищённая HttpOnly-сессия Cloudflare Worker. Пароли и секреты не находятся в коде.

## Редактор
- Вкладка **Редактор страниц**, переключатель: **Общее**, **Главная NOVA**, **HÓF by NOVA**, **Победителей**, **Восток**.
- Группы настроек соответствуют секциям страниц. Поиск по названию и ключу.
- Типы данных: текст, описание, фото/логотип, HTTPS/внутренняя ссылка, иконка из разрешённого набора, видимость некоторых блоков.
- Русский и английский можно менять отдельно. В общих полях ссылок/изображений/иконок один вариант для обоих языков.
- Справа — просмотр текущей страницы. Клик по отмеченному элементу выбирает соответствующее поле. Введённый текст, фото, значок и ссылка показываются в предварительном просмотре до публикации. Технические секции и компоненты не позволяют перетаскивать или менять HTML — это редактор содержимого, **не** drag-and-drop конструктор разметки.
- Кнопка **Опубликовать изменения** сохраняет поля в Cloudflare D1. JPG/PNG/WebP до 8 МБ загружаются в R2 через защищённый API.
- Для меню Востока выбрать **Восток → Первый экран → Адрес QR-меню**; рядом показан существующий адрес, можно поменять и проверить ссылку. То же для HÓF и Победителей.
- URL разрешены только безопасные HTTPS, `/внутренняя-страница` или `#раздел`. `javascript:`, `data:`, протокол `http:` и произвольный HTML запрещены.
- На странице HÓF можно менять лого, фирменные знаки, название кнопок, слоган, фотографию, тексты и переходы. Форма бронирования сохраняет внутренний ID `zyb`, он не редактируется как текст.
- Старая вкладка **Старый редактор** оставлена как резервный путь. Вкладка **События и афиши** продолжает управлять реальными мероприятиями.

## Безопасность и ограничения
- Перевод английских полей можно исправить вручную. Явно сохранённый английский вариант имеет приоритет над автоматическим.
- Внешние ссылки и файлы проверяются на клиенте и повторно на сервере. Неизвестные SVG нельзя загружать: только проверенные фирменные SVG внутри проекта.
- Клики в предпросмотре служат выбором поля и не должны запускать бронирование или открывать внешние сайты.
- Редактор охватывает зарегистрированные поля сайта и ограниченное управление видимостью. Не позволяет произвольно добавлять новые компоненты, менять сетку, переставлять блоки, создавать пользовательские формы или редактировать исполняемый код. Это сделано намеренно, чтобы владелец не мог случайно отключить бронирование и навигацию.
- Содержимое обновляется на сайте без новой сборки; некоторые кешированные браузером страницы могут потребовать обновления.
- База данных, медиа и события при публикации новой версии редактора не мигрируют и не стираются. Существующие значения остаются прежними.

## Откат
GitHub ветка `backup/nova-before-cms-builder-20261107` сохраняет исходный код до нового редактора. При откате изменённые через админку поля D1/R2 остаются на месте; вернуть отдельные пользовательские значения нужно из резервной копии базы, если она была создана.
