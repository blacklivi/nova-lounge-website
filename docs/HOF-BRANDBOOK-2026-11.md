# HÓF by NOVA — минимальная страница, 07.11.2026

Источники: предоставленные `HOF.pdf`, `Logo.svg` и комплект чёрно-белых/оранжевых версий логотипа.

## Фирменная система
- After Hours — `#000000`, First Light — `#FFFFFF`, Amber Pulse — `#F04902`.
- Официальная геометрия логотипа и знака перенесена из пользовательского `Logo.svg`, без ручной перерисовки, в `hof-wordmark-orange.svg`, `hof-wordmark-black.svg`, `hof-wordmark-white.svg`, `hof-mark-black.svg`. Оригинал PDF остаётся референсом.
- В типографике интерфейса применяется Manrope, нормальное межбуквенное расстояние, естественные переносы заголовков, неразрывные пробелы для предлогов. Для названия HÓF использовать SVG, а не текстовый заменитель.
- Контрастные поверхности: главный экран чёрный/оранжевый, короткий блок концепции белый/чёрный, афиша оранжевый/чёрный, контакты чёрный/белый.

## Новая компактная структура
1. Первый экран: фирменный оранжевый HÓF, by NOVA, слоган, «Афиша», «Забронировать стол». Отсутствует декоративная фоновая фотография.
2. Концепция: одна короткая фраза, направления музыки, вечеринок, кухни и бара; кнопка меню.
3. Афиша: до двух **реальных опубликованных** ближайших мероприятий `zyb`, без демонстрационных постеров или вымышленных анонсов. Если мероприятий нет — компактная текстовая заглушка.
4. Контакты: логотип, адрес, бронирование и контакты.
Большой общий футер NOVA на странице HOF сокращён, но навигация по другим заведениям доступна в шапке сайта.

## Сохранено
- Тот же URL `/spaces/zybitskaya` и ID бронирования `zyb`; существующие CMS, D1/R2, меню и серверная логика не изменены.
