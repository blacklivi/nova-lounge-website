# HÓF by NOVA — брендбук и правила для сайта
Источник: файл пользователя `HOF.pdf`, 3 страницы (Figma export, 06.11.2026).

## Из PDF
- Стр. 1: визуальный пример — крупный белый HÓF на чёрно-оранжевой фотографии с тёплым отражением стекла.
- Стр. 2: основная версия логотипа — **HÓF** с фирменной наклонной плашкой над «О»; альтернативная версия — только буква «Ó» с этой плашкой. Защитное поле вокруг основного логотипа не менее толщины основного штриха буквы, вокруг альтернативного — толщины нижней части наклонного элемента. Нельзя помещать другую графику или текст внутри защитного поля.
- Стр. 3: палитра: **After Hours** чёрный `#000000`; **First Light** белый `#FFFFFF`; **Amber Pulse** оранжевый `#F04902`.

## Имплементация
- Оригинальные контуры знака извлечены векторно из страницы 2 в `public/media/hof-wordmark.svg` и `public/media/hof-symbol.svg`; не пересоздавать знак наборным текстом, не менять контур/наклон/пропорции.
- Редизайн ограничен HÓF / Зыбицкая (`/spaces/zybitskaya`). Общий сайт и страницы Победителей/Востока сохраняют NOVA.
- Чёрный фон, контрастный белый текст, оранжевые акценты и кнопки, тёплая чёрно-оранжевая обработка существующих фотографий и мотивы отражений стекла. Фирменные фотографии PDF используются как референс; существующие фотографии сайта не выдаются за новые фотографии HÓF.
- В PDF отдельная текстовая гарнитура не указана; для обычного текста сохранить Manrope и ранее утверждённые ограничения по трекингу, переносам и висячим предлогам. Официальное начертание HÓF всегда SVG.
- По доступности: мелкий текст на белом — чёрный, а не `#F04902`; цвет применяется для акцентной плашки.
- Постеры в разделе событий — обозначенные демонстрационные варианты. При появлении реальных мероприятий они подменяются содержимым для внутреннего ID `zyb`.
- Бронирование, данные CMS, ссылки, маршруты и серверная логика не изменяются.
- Анимации уважают `prefers-reduced-motion`, на мобильной странице CTA остаются перед фиксированной кнопкой.
- Проверки: `npm run check` включает контроль палитры, SVG, типографики и привязки бронирования.
